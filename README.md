# zif.my.id

Personal portfolio of Fatahillah Rachman, APT Website Officer at the ASEAN Secretariat with a background in hospital IT, PHP, SQL and Python.

Live: https://zif.my.id

## Structure

- `index.html`: the whole site (markup, styles and scripts in one file)
- `assets/Fatahillah_CV.pdf`: downloadable CV
- `assets/favicon.ico`: site icon
- `google96ab9d5db2b2eedb.html`: Google Search Console verification, keep it

No build step. Open `index.html` in a browser or serve the folder with any static host.
